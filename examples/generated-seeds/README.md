# Optional model-generated starting artifacts

`A.json` and `B.json` preserve workflows generated by the optimizer in an earlier local run. The preparation script replaces only their solver system messages with the selected Markdown text. A retains its model-generated answer-processing code; B retains its graph and bindings.

These are explicit starting artifacts, not hand-authored solution templates or performance guarantees. They contain no evaluation rows, task answers, dataset files or saved scores. The user-prompt runner evaluates them again before optimization. The empty-history A/B entry point does not load these files unless `--seed-proposal` is supplied.
